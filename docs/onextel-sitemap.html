AI LAYER · XAURA

Served under /xaura. A copilot with its own sidebar, plus AI-native versions of engagement screens to show where AI enters day-to-day work.

Copilot chat /xaura

Ask anything about campaigns and customers

  • Modes: Collaborative (step by step) or Autonomous (end to end)
  • Starter prompts: Revenue monitoring, Seasonal trend, CTR, QBR report, Channel anomalies
  • Deep research: editable plan → long-form report
  • Artifacts: performance dashboards, executive summary, WhatsApp text / media / carousel previews

Agents

Specialists that join a thread

  • xAura: plans and optimises campaigns
  • Content: writes copy per segment
  • Segment: finds and sizes audiences
  • Scheduler: best send time
  • Insight: performance analysis
  • Journey: multi-step, multi-channel flows
  • Custom agents: create and configure your own

Copilot sidebar

Workspace around the chat

  • New chat · Chats · Search
  • Reports (customisable) · Scheduled · Bookmarks
  • Decisioning engine · OneXtel console
  • Settings

  • Setup: brand wiki, event mapping, guardrails → review
  • Preview board · Configuration
  • Objective: Goal → Audience → Content → Preview → Launch
  • Objective performance dashboard
